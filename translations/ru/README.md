# GeoView

Веб-приложение для моделирования, оптимизации и визуализации пластовых процессов со встроенным ИИ-помощником.

Легкое. Современное. С открытым исходным кодом.

<img src="static/geoagent_demo.gif" width="70%"/>

## Функции

* **Поддержка формата ECLIPSE:** Анализ стандартных файлов моделей пласта
* **Эталонное моделирование:** Быстрое и точное моделирование с использованием симулятора JutulDarcy
* **Оптимизация NPV:** Автоматическая настройка графика работы скважин для максимизации экономических показателей
* **Многомерная визуализация:** Интерактивная аналитика для статических и динамических данных (3D, 2D и 1D)
* **Рабочие процессы с поддержкой ИИ:** Автономный агент ИИ для оптимизации инженерных задач и анализа данных.

## Требования

| | Необходимо для | Примечание |

|---|---|---|

| Python 3.13 | всего | Версии 3.11 и 3.12 также работают; мы тестируем 3.13 |

| `git` в `PATH` | всего | GeoCode и GeoRead устанавливаются из GitHub, а не из PyPI |

| [Julia](https://julialang.org/downloads/) | пластовое моделирование | только для опций **Simulate** и **Optimize** |

| [uv](https://docs.astral.sh/uv/) | чат ИИ | GeoAgent работает в собственной виртуальной среде, см. [Включение чата](#enabling-the-chat-geoagent) |

## Установка в виде пакета

Создайте новую виртуальную среду с Python 3.13 и установите зависимости проекта:

pip install "git+https://github.com/geo-kit/geoview.git"

Это установит GeoCode и GeoRead вместе с ним. Для моделирования пласта установите `Julia` с [https://julialang.org/downloads/](https://julialang.org/downloads/). Затем установите зависимости JutulDarcy:

>

> julia --project="$(python -c "import geocode, pathlib; print(pathlib.Path(geocode.__file__).parent / 'bin')")" -e "using Pkg; Pkg.instantiate()"

После установки запустите в терминале:

geoview

Это должно открыть новую вкладку в вашем браузере по умолчанию по адресу http://localhost:8080/ с домашней страницей приложения.

* **Контекстная справка:** Щелкните значок справки в правом верхнем углу, чтобы получить краткое описание текущей страницы.

* **Всплывающие подсказки:** Наведите курсор на любую кнопку или значок, чтобы увидеть ее описание.

Для работы чата с ИИ требуется еще один шаг, поскольку агент — это отдельный процесс, который `pip` не может запустить автоматически:
см. [Включение чата](#enabling-the-chat-geoagent).

## Установка из исходного кода

Клонируйте оба репозитория в одну директорию:

git clone https://github.com/geo-kit/geoview.git

git clone https://github.com/geo-kit/geocode.git

Установите зависимости в `GeoCode` и `GeoView` с помощью

pip install -r requirements.txt

GeoRead указан в GeoCode, поэтому он поставляется вместе с ним. Для моделирования пласта установите `Julia` с [https://julialang.org/downloads/](https://julialang.org/downloads/). Затем установите зависимости JutulDarcy:

>

> julia --project=GeoCode/geocode/bin -e "using Pkg; Pkg.instantiate()"

Затем перейдите в каталог GeoView и запустите в терминале

python -m geoview.app

чтобы запустить приложение.

## Включение чата (GeoAgent)

Панель чата взаимодействует с [GeoAgent](https://github.com/geo-kit/GeoAgent), который GeoView запускает
и останавливает за вас. GeoAgent работает в собственной виртуальной среде, поэтому ему требуется собственная копия,
независимо от способа установки GeoView.

**1. Клонируйте агента.** Если вы установили GeoView из исходного кода, он находится рядом с `GeoView/` — именно там GeoView по умолчанию ищет свой файл:

```
your-workspace/
├── GeoView/
└── GeoAgent/
```

git clone https://github.com/geo-kit/GeoAgent.git

Если вы установили GeoView как пакет, поместите его куда угодно и перейдите к шагу 5.

**2. Установите его** с помощью [uv](https://docs.astral.sh/uv/), из `GeoAgent/`:

uv venv && uv pip install -e .

Это создаст файл `.venv`, из которого GeoView будет запускать агент.

**3. Добавьте свой API-ключ.** Скопируйте файл `.env.example` в файл `.env` и укажите ключ для используемого вами провайдера,
по одному на строку:

```
OPENAI_API_KEY=sk-...
```

GeoView считывает этот файл при запуске и передает значение только процессу агента.

**4. Запустите GeoView с параметром `--agent`:**

geoview --agent --agent-provider openai --agent-model gpt-5-mini

Кнопка чата появится на вкладке «Главная». Спросите о текущей открытой модели (сетка, скважины,
фазы, есть ли результаты) или попросите агента найти и открыть модель, запустить моделирование,
или заполнить форму оптимизации.

**5. Только для установки пакетов — укажите GeoView путь к папке с загруженными файлами.** Упакованный GeoView находится в
`site-packages` и не имеет доступа к соседним каталогам, укажите абсолютный путь один раз:

```powershell
$env:GEOVIEW_AGENT_DIR = "C:\path\to\GeoAgent"
geoview --agent --agent-provider openai --agent-model gpt-5-mini
```

```bash
export GEOVIEW_AGENT_DIR=/path/to/GeoAgent
geoview --agent --agent-provider openai --agent-model gpt-5-mini
```

Если GeoView завершает работу с ошибкой `GeoAgent langgraph executable was not found: ...`, шаг 2 не был
выполнен в этом каталоге, или `GEOVIEW_AGENT_DIR` указывает в другое место.


Вам **не** нужно устанавливать параметр `GEOVIEW_RESULT_DIR`. GeoView передает его дальше.

## Параметры запуска

К команде запуска приложения можно добавить несколько необязательных параметров:
* --server, чтобы предотвратить открытие новой вкладки в браузере
* --app, чтобы запустить приложение в отдельном окне, а не в браузере
* --port 1234, чтобы изменить порт по умолчанию 8080, например, на 1234
* --agent, чтобы запустить AI-agent
* --ru, чтобы переключить чат на русский язык
* -vr или --vtk_remote, чтобы включить удаленный рендеринг vtk вместо локального рендеринга по умолчанию с использованием vtk webassembly.

## Выбор модели чата

При запуске с флагом --agent GeoView запрашивает поставщика и модель LLM.
Доступные варианты: LM Studio, Ollama и OpenAI.

Для неинтерактивного запуска укажите оба значения явно:

```powershell
python -m geoview.app --agent `

--agent-provider ollama `

--agent-model qwen2.5:7b
```

Используйте `--agent-base-url` для указания нестандартной локальной или совместимой с OpenAI конечной точки:

```powershell
python -m geoview.app --agent `
--agent-provider lmstudio `
--agent-base-url http://127.0.0.1:1234/v1 `
--agent-model some-model-id
```

Соответствующие переменные среды: `GEOVIEW_AGENT_PROVIDER`,
`GEOVIEW_AGENT_MODEL` и `GEOVIEW_AGENT_BASE_URL`.

Ключи Cloud API считываются из среды (`OPENAI_API_KEY`). Если ключ еще не установлен, GeoView загружает его из `GeoAgent/.env`, поэтому шага 3 выше достаточно. GeoView не запускает локальные серверы моделей и не загружает модели.

## Параметры рендеринга

По умолчанию рендеринг выполняется локально в браузере пользователя с использованием функциональности vtk webassembly.
Чтобы включить удаленный рендеринг vtk, используйте параметр `-vr` или `--vtk_remote` при запуске приложения.
Обратите внимание, что функциональность приложения немного отличается при локальном и удаленном рендеринге.

## Написание скриптов

Приложение позволяет писать и выполнять скрипты на Python для
преобразований и расчетов моделей пластов. Скрипт должен
быть основан на фреймворке `GeoCode`
[https://github.com/geo-kit/GeoCode](https://github.com/geo-kit/GeoCode).
Ознакомьтесь с [документацией](https://geo-kit.github.io/GeoCode/)
и посмотрите
[примеры](https://github.com/geo-kit/GeoCode/tree/main/notebooks)
в репозитории `GeoCode`, чтобы подготовить скрипт.
